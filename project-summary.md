# Resumo do projeto

O AI Rapid Triage Agent é um workflow de suporte de TI criado no n8n.

Ele recebe uma solicitação pelo chat, utiliza inteligência artificial para fazer a primeira triagem, organiza os dados com JavaScript, registra o ticket no Google Sheets, envia um resumo pelo Gmail e devolve o resultado ao usuário.

A explicação completa está no [README](./README.md) e uma versão simplificada está em [`docs/entenda-o-projeto.md`](./docs/entenda-o-projeto.md).
